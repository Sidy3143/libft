# LIBFT Project


## Description

**Libft** is the first project of the 42 Common Core curriculum. Its goal is to recreate a collection of standard C library functions, along with additional utility functions, by implementing them from scratch.

The project provides a deeper understanding of fundamental C programming concepts, including:

- Memory management and dynamic allocation.

- Pointers and pointer manipulation.

- String manipulation.

- Data structures and linked lists.

- Memory operations and low-level programming.

- Static library creation and compilation.


## Instruction

### Requirements

- A C compiler (cc, gcc or clang).

- GNU Make.

- A Unix-like environment.

### Compilation

Clone the repository:

```
git clone <repository_url>
cd libft
```

Compile the library:

```
make
```

This generates the static library **libft.a**.
